# C# Collections, LINQ, XML & Concurrency

Practice projects and exam preparation in C# from my 2nd-year programming modules at Eduvos. Each folder is its own Visual Studio console project.

## Topics covered

- **Collections** – List, Dictionary, Queue, Stack, HashSet (`CollectionsW2B2 ...`, `CollectionsW3B2 ...`, `List Practice`, `Dictionary Practice`, `HashSet Practice`)
- **LINQ** – querying collections (`LINQExamPrep`, `LINQweekActivity`)
- **XML** – reading, writing, and editing XML three ways: DOM, LINQ to XML, and streaming (`XMLW6B2 ...`, `XMLW7B2 ...`, `XmlDocument Practice`)
- **Concurrency** – threads, `Parallel.For`, and parallel data aggregation (`ConcurrencyW4B2 ...`)
- **File handling** – reading and writing files (`ExamPrep B1 W7 FileHandling`)
- **Arrays** – `Array Practice`, `ExamPrep B1 W5 Arrays`
- **Exam practice** – mock and practice exam questions (`MockExam...`, `Initial Final Exam...`)

## How to run

1. Open any project's `.sln` file in **Visual Studio 2022** or newer
2. Press **F5** to run
